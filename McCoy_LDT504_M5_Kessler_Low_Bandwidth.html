Help and saved progress

Using this workbook

Work at your own pace. Select one recommendation and one reason, then submit them together. You can change selections before submitting. Afterwards, your answers stay available for review.

Use Tab to move between controls, arrow keys within radio groups, and Space to select. The report stays in the page above each task. There is no response timer.

Assessment and review

There are four questions worth five points. Question 2 has two one-point parts. Feedback appears after all four questions are submitted. Next review moves between question reviews; practice uses separate Start practice and Check answer buttons.

Saving on this device

This file works without a connection. When browser storage is available, it saves your selections and progress on this device. Reopen the same file in the same browser to try resuming. Moving the file, clearing browser data, or using another device may make that saved progress unavailable. Nothing is sent to a server.

If saving is unavailable, keep the tab open until you finish. Refreshing or closing it may lose your progress.

This removes this workbook’s saved progress and starts a new attempt. Your current answers and certificate will be cleared.
